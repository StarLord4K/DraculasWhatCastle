# 🏰 Dracula's What Castle?

> **"What is a man? A miserable little pile of secrets!"**  
> เกมแนว Text-Based Adventure โกธิคตลกร้ายที่ผสมผสานระบบ **Rogue-lite** และกลไก **Fear Level** สุดบีบหัวใจ คุณจะได้ออกสำรวจปราสาทแดร็กคิวล่า เลือกเส้นทาง เอาชีวิตรอด และค้นหาความลับเพื่อปลดล็อกฉากจบทั้งหมดในวงจรลูปมรณะที่ไม่สิ้นสุด!

---

## 🕹️ ภาพรวมของเกม (Game Overview)

**Dracula's What Castle?** คือเกมสวมบทบาทผ่านข้อความตัวหนังสือบนเว็บเบราว์เซอร์ ที่จะพาคุณเข้าไปหลงทิศหลงทางในปราสาทแวมไพร์โบราณ ทุกการตัดสินใจมีผลต่อพลังชีวิต สภาพจิตใจ และชะตากรรมของคุณ 

* **ระบบวงจรลูปมรณะ (Rogue-lite Loop):** ตราบใดที่คุณยังเก็บฉากจบไม่ครบ 4 รูทหลัก แดร็กคิวล่าจะไม่มีวันตายอย่างถาวร! เมื่อรอดชีวิตออกไปได้ วงจรเวลาจะรีเซ็ตพาคุณกลับมาที่หน้าปราสาทอีกครั้ง จนกว่าจะปลดล็อก **True Ending** ได้สำเร็จ
* **เกจระดับความกลัว (Fear Level):** สภาพจิตใจคือหัวใจสำคัญ หากเกจความกลัวพุ่งสูงเกินไป ตัวละครจะเกิดอาการสติหลุด ช็อก และเสียพลังชีวิตกะทันหัน
* **ระบบสะสมฉากจบ (Ending Tracking):** ตัวเกมใช้ `localStorage` ในการบันทึกความคืบหน้าของฉากจบและลูปที่คุณค้นพบโดยอัตโนมัติ

## 📜 วิธีการเล่นคร่าว ๆ (How to Play)

1. **อ่านสถานการณ์:** สังเกตการบรรยายฉาก บาดแผล (HP) และเกจระดับความกลัวให้ดี
2. **เลือกเส้นทาง:** คลิกเลือกตัวเลือกตัดสินใจในแต่ละห้อง การกระทำบางอย่างอาจให้ไอเทม ฟื้นฟูสภาพจิตใจ หรือนำไปสู่กับดักอันตราย
3. **จัดการไอเทม:** ไอเทมอย่าง *ลิ่มไม้คาร์เพเทียน*, *น้ำมนต์ศักดิ์สิทธิ์*, หรือ *กุญแจโบราณ* จะเป็นตัวกำหนดว่าคุณสามารถปลดล็อกฉากจบแบบใดได้บ้าง
4. **ปลดล็อกความลับให้ครบ:** สะสมฉากจบหลักทั้ง 4 รูปแบบ เพื่อสลายคำสาปแห่งปราสาทและสังหารแดร็กคิวล่าลงอย่างถาวร!

## 🛠️ โครงสร้างเทคโนโลยี (Tech Stack)

* **HTML5:** โครงสร้างหลักแบบ Single Page Application (SPA)
* **Tailwind CSS:** ตกแต่งหน้าจอ UI ในธีมโกธิคดาร์กด้วย utility-first styling
* **JavaScript (Vanilla JS):** จัดการ State ของเกม, เควสต์ไอเทม, ระบบเกจความกลัว และระบบ `localStorage`
